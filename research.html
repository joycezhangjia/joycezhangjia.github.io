Selected Research

My work focuses on secure, intelligent, and low-latency networked systems. Below are three representative research directions led as first or corresponding author.

Routing Security

Reliable Route Origin Validation with Multi-Source Data

Hecate combines RPKI ROAs, IRR records, global BGP observations, and local routing data to improve the coverage, timeliness, and accuracy of route origin validation. Complementing this systems work, Right the Ship studies why many ROV-invalid routes are nevertheless legitimate and offers practical guidance for safer filtering.

Transport Security

Receiver-Driven Attacks on QUIC Congestion Control

QUDIT exposes a protocol-level vulnerability in which a malicious QUIC receiver manipulates Host Delay feedback to distort the RTT estimates used by delay-based congestion-control algorithms. The attack requires only ordinary receiver access, without bottleneck visibility or packet injection.

Key result. QUDIT reduces victim throughput by up to 60% within 0.3 seconds, with amplification gains of 200× to 600×.

AI-Driven Networking

Intelligent Transport for Mobile Web Services

Across WiseTrans, Floo, and WiseStart, I developed learning-assisted mechanisms that select transport protocols, switch congestion-control algorithms using application-level QoE, and accelerate connection startup with prior knowledge. These systems were implemented and evaluated in large-scale mobile web services.

Key results. The systems reduce request completion time by up to 25.8%, improve QoE by 14.3% on average, and reduce first above-the-fold time by 25.43%.
